Aturan Pemilihan Template
  • Konten publik → T1 (pintu masuk), T2 (koleksi), artikel memakai T2 tanpa sidebar (prosa 720px).
  • Transaksi warga → T3; selalu diakhiri layar konfirmasi + nomor registrasi.
  • Gerbang akses → T4 — sisi ilustrasi tidak pernah memuat informasi wajib.
  • Aplikasi internal → T5 sebagai cangkang; isinya T6 (kerja percakapan) atau T7 (pemantauan).
  • PPID Mobile (Flutter) memakai degradasi mobile template ini sebagai acuan 1:1.

05 Aturan Wajib

Checklist Layout — QA & Aksesibilitas

Aturan tidak bisa ditawar sebelum halaman dinyatakan selesai — dirumuskan dari temuan audit ketiga modul (Juli 2026).

Nol overflow horizontal di 390px

Uji document.scrollWidth ≤ 390 di tiap halaman. Penyebab tersering (temuan A1-01, A2-01): utilbar tanpa media query, grid-template-columns inline mengalahkan media query, dan item grid tanpa min-width:0.

Target sentuh ≥ 44×44px

Semua kontrol interaktif — termasuk tombol utilbar, chip filter, dan tombol tutup drawer (temuan A2-04, A3-06). Rapatkan visual dengan padding, bukan dengan memperkecil area klik.

[hidden]{display:none!important} di tiap pages.css

CSS komponen (display:flex/grid) mengalahkan aturan UA untuk atribut hidden — tanpa penegasan ini panel langkah/tab "tersembunyi" tetap tampil.

Reflow 320px & teks 200%

WCAG 1.4.10: konten tetap utuh satu kolom pada lebar 320px dan pembesaran teks 200% (toolbar aksesibilitas hingga 140–200%) tanpa kehilangan informasi.

Drawer & panel: fokus terkelola

Saat terbuka: fokus masuk panel, Escape menutup, scrim dapat diklik, dan visibility mengikuti transisi agar tautan tersembunyi tak menerima fokus (temuan A3-01, A3-03).

Urutan konten = urutan DOM

Degradasi mobile menumpuk sesuai urutan sumber — dilarang menata ulang dengan order yang memutus urutan baca pembaca layar; satu h1 per halaman, hierarki heading berurutan.

Hormati prefers-reduced-motion

Animasi drawer, slideshow otomatis, dan reveal-on-scroll dimatikan; konten tampil langsung tanpa menunggu animasi.

Verifikasi ganda 1440px + 390px

Protokol rilis: render Playwright kedua viewport, nol error JS, link-check, dan uji interaksi kunci — baru halaman boleh dicentang di checklist.

Ukuran Sentuh Minimum
44 38 32 44px = lulus. Di bawahnya hanya boleh bila jarak antar-target ≥ 24px dan ada alternatif setara yang lebih besar.
