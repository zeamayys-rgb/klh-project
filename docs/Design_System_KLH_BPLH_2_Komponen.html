01 Aset Visual Inti

Lambang, Motif & Media

Seluruh aset visual non-ikon yang dipakai ketiga modul: berkas lambang produksi, motif daun dekoratif KLH.leafmark(), placeholder media bergradien, dan pustaka foto berita. Semua aset digandakan ke folder assets/img/ tiap modul agar mandiri saat di-zip.

Placeholder Media — .ph

02 Ikonografi Produksi

Ikon KLH — 71 ikon garis

Set ikon produksi yang tertanam di ketiga modul (assets/js/components/icons.js, identik byte-per-byte): SVG garis 24×24, stroke-width 1.8, currentColor. 57 ikon inti dipakai semua modul; 14 ikon tambahan (kanal & ticketing) saat ini khusus Modul 03.

Cara Pakai
<!-- dekoratif (otomatis aria-hidden) -->
<klh-icon name="leaf" class="icon"></klh-icon>

<!-- fungsional (role="img" + aria-label) -->
<klh-icon name="bell" label="Notifikasi baru"></klh-icon>

<!-- sebagai string di komponen JS -->
KLH.iconSVG('search', 'icon icon--sm')

Ukuran via kelas: .icon 24px · .icon--sm 18px · .icon--lg 32px. Nama tak dikenal jatuh ke leaf.

Aturan
  • Ikon fungsional wajib label (menghasilkan aria-label); dekoratif dibiarkan aria-hidden.
  • Warna tidak di-hardcode — ikon mewarisi currentColor dari teks di sekitarnya.
  • Status tidak boleh disampaikan lewat ikon/warna saja — selalu dampingi teks.
  • Dilarang emoji sebagai ikon pada deliverable resmi.
  • Ikon baru mengikuti kanvas 24×24, garis 1.8, ujung membulat; tambahkan ke registry icons.js, jangan berkas lepas.
